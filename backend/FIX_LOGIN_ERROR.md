# Login errors

Follow [TROUBLESHOOT_LOGIN.md](TROUBLESHOOT_LOGIN.md) for the current diagnostic and
user reset workflow. Credentials must use complete scrypt hashes in single-quoted
AUTH_USERS values. Use setup_user_password.sh rather than passing plaintext
passwords on the command line or manually substituting hashes.

The canonical service/configuration instructions are in [DEPLOYMENT.md](../DEPLOYMENT.md).
